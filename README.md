//TITLE
Vibe Arcade is an open source HTML arcade game platform.


//PURPOSE and BLURB
The purpose of Vibe Arcade is to provide a space for collaboration, learning about Github, coding, vibe coding
and user generated content.

Version 1.0 is an incredibly simple flat HTML file with two embedded games 'Paddle Ball' and 'Jaggy Snake'
No installation is required, simply copy the HTML file and run it locally, or visit the published page where the latest version will be running.


//MAKING CHANGES AND COLLABORATION
Please checkout a branch to make any changes and raise pull requests to merge to the main branch.
When making changes, try to keep to the original look and feel of the platform; or explicitly state that you are changing the theme.


//DATA COLLECTION AND PRIVACY
This project collects and stores game high scores submitted by players.
Only the following information is recorded:

-Score value
-Game identifier
-Optional player name or nickname (if provided)

No personal, sensitive, or identifying information is collected.
All stored scores are used solely for displaying leaderboards and improving gameplay features.
By submitting a score, players agree that their score and chosen display name may be publicly visible.

All data is provided voluntarily by players and can be removed or reset by the project maintainer at any time.
